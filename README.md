# 🎨 Color Palette

Default color palette used across the project.

## Primary Colors

| Name          | Hex       |
| ------------- | --------- |
| Primary       | `#0D6EFD` |
| Primary Hover | `#0B5ED7` |

## Background & Cards

| Name       | Hex       |
| ---------- | --------- |
| Background | `#FFFFFF` |
| Card       | `#FFFFFF` |

## Text Colors

| Name           | Hex       |
| -------------- | --------- |
| Primary Text   | `#212529` |
| Secondary Text | `#6C757D` |

## Borders

| Name   | Hex       |
| ------ | --------- |
| Border | `#DEE2E6` |

## CSS Variables

```css
:root {
    --primary: #0D6EFD;
    --primary-hover: #0B5ED7;

    --background: #FFFFFF;

    --card: #FFFFFF;

    --text-primary: #212529;
    --text-secondary: #6C757D;

    --border: #DEE2E6;
}
```

## Design Notes

* Clean and modern Bootstrap-inspired palette.
* High readability and accessibility.
* Neutral whites and grays for a professional look.
* Blue accent color for buttons, links, and interactive elements.
* Suitable for portfolio, dashboard, and utility web applications.
